# Documentation health

**Administration → Documentation health** groups pages that may need attention:

- broken wiki links;
- orphan pages;
- untagged pages;
- pages without an icon;
- pages not updated in the previous six calendar months;
- pages whose configured review is due;
- `draft` pages;
- deprecated pages.

![Documentation health overview with actionable page groups](../assets/screenshots/documentation-health.png)

Documentation health is available in the Kumbuka server. It is not part of generated static sites.
